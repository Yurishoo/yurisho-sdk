# Security Policy

## Reporting a vulnerability

Please report security issues privately to yurishoo  .

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/REPLACE-WITH-yurishoo-GITHUB-USERNAME/yurishoo- -pokeapi-sdk/issues

## Scope

This policy applies to the generated yurishoo   SDK packages published from this
repository (npm, PyPI, Packagist, RubyGems, LuaRocks, and the Go module).

This is an unofficial SDK for the Poké public API, generated by
yurishoo  . It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
